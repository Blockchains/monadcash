PolicyPilot is a policy contract on Monad. Allowlisted recipients, a per-request cap, a total budget, a pause switch and replay-proof request IDs are all enforced on-chain, so an automated executor (bot, AI agent, backend) can only spend inside the rules.

Try a policy check

Simulates execute(requestId, recipient, amount) with a read-only eth_call against the live contract: nothing is signed or sent. By default it calls as the configured executor, so you see exactly what the policy would do.

Pick a preset or enter values, then simulate.

Pause isn't a preset because the contract isn't paused right now, so a real paused rejection is shown under Guardrails instead. Reads only; no gas is spent.

Judge quick-start

  1. Look: this page reads live from Monad testnet. Check the reverted guardrail txs on the explorer, then run a policy check.
  2. Verify: the contract is Sourcify-verified (see explorer). The source is in src/PolicyPilot.sol.
  3. Run: clone the repo, then forge test (17 tests: unit, fuzz, invariant). Optionally run cd indexer && npx envio dev and open this page with ?indexer=http://localhost:8080/v1/graphql.
git clone https://github.com/Blockchains/policypilot-monad
cd policypilot-monad && forge test
anvil & cd executor && npm ci && node e2e-anvil.mjs
cd ../indexer && npm i && npx envio dev

PolicyPilot is a reference implementation built for Monad Metropolis. It runs on Monad testnet with a valueless test token (mUSD), is unaudited, and has no users. Nothing on this page is simulated or invented: values come from live RPC reads, receipts and eth_call, or from your Envio indexer if you set one.
